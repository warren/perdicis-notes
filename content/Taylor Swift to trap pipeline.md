# Taylor Swift to trap pipeline
#publish 
Opened ~[[2024-08-22]] but I forget when I first thought of this.

Anyways the thought is that there's 3 songs that can measure how far you are into genuinely enjoying trap.

1) [Anti-Hero // Taylor Swift](https://youtu.be/gGwN25z7FrE)
    - Catchy.
    - Inoffensive.
2) [Anti-Hero - ILLENIUM remix // Taylor Swift, ILLENIUM](https://youtu.be/nF4Jc9sPPug)
    - Catchy.
    - Inoffensive, provided you're not a diehard TSwift fan.
    - Largely unchanged from the original.
        - Main change is at 1m35s which adds a pop EDM instrumental atop the hook.
    - If you enjoy this, you might like other pop EDM.
3) [STFU // Crankdat](https://youtu.be/O8TxXLLd1fc)
    - Basically incomprehensible to anyone who hasn't listened to trap before (which is funny).
    - Actively enjoyable if you like trap though.
    - Just listen to the first 20 seconds.
